# Password Manager

A desktop password management application built with Python, designed to securely store and manage username:password credentials locally.

## Purpose

This project aims to demonstrate software engineering skills and principles including:

- Secure Data Handling
- Object Oriented Programming
- Automated Testing
- Version Control
- Desktop Application Development
- Database Design and Management

## Status
Currently in the planning and design phase.

## Technologies Used

- Python
- Tkinter
- SQLite
- pytest
- Git/GitHub

## Security Notice
This project is being developed as an educational and portfolio project. It has not undergone professional security auditing and should not be considered a production-ready password manager.
